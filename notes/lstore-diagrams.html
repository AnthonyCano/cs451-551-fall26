L-Store Milestone 1

Build a single-threaded, in-memory, columnar database in Python. Inserts write base records. Updates append tail records. Reads follow the lineage from base to tail.

Due Oct 26, 2026 · 11:59pm
S1

Data model

Columnar base and tail pages, grouped into page ranges. Metadata columns: indirection, RID, timestamp, schema encoding.

S2

Bufferpool

Memory only for now. A page directory maps each RID to its page range, page and offset.

S3

Query interface

insert, select, update and delete by key, plus sum of one column over a key range.

How a select travels through the code

One record, two updates

The example uses the Grades table from __main__.py: 5 columns, key in column 0. Tail records here are non-cumulative, so columns that were not updated hold NULL (shown as —).

  1. insert(906659671, 93, 0, 0, 0)Writes base record b1. Schema 00000. IND empty.
  2. update(906659671, None, 88, None, None, None)Appends t1 with only g1 set. b1.IND = t1. b1 schema becomes 01000.
  3. update(906659671, None, None, 75, None, None)Appends t2 with t2.IND = t1. b1.IND = t2. b1 schema becomes 01100.
  4. select(906659671, 0, [1, 1, 1, 1, 1])Returns [906659671, 88, 75, 0, 0].
  5. delete(906659671)Invalidates b1, t1 and t2 (special RID value or a delete flag). Physical removal waits for the merge in Milestone 2.

Query API to implement

MethodReturns
insert(*columns)True, or False on failure. Every column must be non-NULL.
select(search_key, search_key_index, projected_columns_index)List of Record objects with only the projected columns.
update(primary_key, *columns)True or False. None means "leave this column unchanged".
delete(primary_key)True, or False if the key does not exist.
sum(start_range, end_range, aggregate_column_index)Sum of one column over the key range, or False if the range is empty.
